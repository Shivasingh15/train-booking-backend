# 🚆 Train Booking Backend

A RESTful backend application for a Train Booking System built using Spring Boot, Java, Spring Data JPA, Hibernate, MySQL, Spring Security, and Gradle.

## 🛠️ Tech Stack

- Java 21
- Spring Boot 3.5.16
- Spring Web
- Spring Data JPA
- Hibernate
- Spring Security
- MySQL
- Gradle
- Lombok
- REST API
- Postman
